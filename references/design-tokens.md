# 预置设计 Token —— 欧美 App 通用默认（v1.1）

> 本 skill 默认面向**欧美消费者 App/网页原型**。风格基线：**Apple HIG · Uber · BirdBuddy**。
> 反例红区（默认禁止做出这种观感）：**滴滴 / 淘宝式国内促销 UI**。
> 优先级：**用户品牌 token > 本默认值**。用户给了就全量替换；无则用本表并交付注明「默认欧美 token」。
> Maygrove 等自有品牌项目关联对应 design-system skill，不套本表品牌色。

## 1. 风格三锚点（先理解再取值）

| 参考 | 学什么 | 对应反例（不要） |
|---|---|---|
| **Apple (iOS/HIG)** | 中性灰阶、系统字体、深浅双主题标配、内容>装饰、一屏一主操作 | 促销弹窗、开屏广告、满屏红点 |
| **Uber** | 单一品牌色 + 黑白高对比、卡片化流程、大而清晰的主 CTA、克制动效 | 高饱和红橙渐变按钮、金币红包视觉 |
| **BirdBuddy** | 温暖自然的真实照片/插画、卡片圆角、digest 式通知、类「真实产品」 | 彩色贴纸角标、五颜六色图标、倒计时贴纸 |

## 2. 颜色（中性 + 系统语义，Apple 灰阶）

| Token | 值 | 用途 |
|---|---|---|
| bg / surface | `#F5F5F7` / `#FFFFFF` | 页面背景（Apple 浅灰）/ 卡片 |
| ink / ink-2 / ink-3 | `#1C1C1E` / `#6E6E73` / `#AEAEB2` | 正文 / 次级 / 占位禁用 |
| primary（占位） | `#007AFF`（系统蓝） | **占位主色**——品牌主色存在时必替换；hover `#0066D6`、pressed `#004E9E` |
| primary-soft | `rgba(0,122,255,.10)` | 选中卡填充、ghost 按钮底 |
| border / divider | `#E5E5EA` / `#F2F2F7` | 细线 |
| success / warning / error | `#34C759` / `#FF9500` / `#FF3B30` | 系统语义色，**只表状态**，禁止当装饰色 |
| 深色模式 | bg `#000000` · surface `#1C1C1E` · ink `#FFFFFF` · ink-2 `#AEAEB2` · primary `#0A84FF` | 深浅双主题是标配 |

规则：正文主色文字用 ink 近黑（不拿 primary 做正文）；信号色一屏≤1 处主用；无促销红黄渐变、无彩虹色块。

## 3. 字体 / 间距 / 圆角（Apple HIG 网格）

- 字体：**系统原生栈**（iOS SF Pro / Android Roboto / Web -apple-system,Segoe UI），不加 web 字体；英文界面不要用中文 UI 字重习惯
- 字号阶梯：34 Large Title / 22 Title / 17 Body / 15 / 13 / 11 Caption；标题负字距，正文 0；字重 400-700
- 间距：8pt 栅格；屏边距 ≥16；卡片 padding 16；卡片间距 12-16；区块间距 24-32；触控目标 ≥44pt，主 CTA 高 ≥48
- 圆角：按钮 10-12（Uber 风格可全胶囊 999）、卡片 16-18、Sheet/弹窗顶部 24-32
- 阴影：染色阴影 `rgba(0,0,0,.06-.12)` 小面积，多数表面靠颜色分层不靠阴影

## 4. 组件基线（欧美语感）

- 按钮：primary 实心 1 个 / 次级 ghost / 文字链接；主 CTA 文案**动词开头**且短（Continue / Start growing / Book now）
- 列表行：内容左对齐、`›` 进详情（心智模型）；不要「数字角标+红点」轰炸
- 通知：**digest 式汇总**（Bird Buddy 模式），不逐事件 spam；红点全屏 ≤1-2 处
- 图标：统一线性（stroke 1.5-2px）单色，同一页面同色（默认 ink/primary），禁每图标各色
- 反馈：Toast / inline 错误；操作后 100ms 内可见变化；尊重 reduced-motion
- 商业化克制：无金币/券/红包/倒计时贴纸、无自动轮播 Banner、无促销弹窗；订阅/内购走标准系统 sheet

## 5. 交付前自查（欧美 vs 反例红区）

| 维度 | ✅ 欧美（Apple/Uber/BirdBuddy） | ❌ 反例（滴滴/淘宝式，禁止） |
|---|---|---|
| 信息密度 | 一屏一个主任务，用留白分层级 | 一屏塞满入口/红包/Banner |
| 色彩 | 中性底 + 单一品牌色；语义色只表状态 | 高饱和红橙促销渐变 |
| 促销视觉 | 无金币券红包；商业化克制 | 贴纸、角标、倒计时 |
| Banner | 无自动轮播 | 顶部大轮播 |
| 图标 | 单色统一线性 | 每个 icon 不同颜色 |
| CTA | 主操作唯一、次级降级 | 多个等权彩色按钮 |
| 模式 | 深浅双主题 | 仅浅色 + 促销亮色 |
| 文案 | 短、动词开头、口语 | 夸张促销词堆砌 |

## 6. 替换规则

1. 每次使用先问「你有自己的设计 token 吗？」；给了 → 解析并**全量替换**（颜色/字体/间距/圆角）
2. 没给 → 用本预置（欧美默认）并在交付注明「默认欧美 token」
3. 换 token 校验：主色与正文对比 ≥ WCAG AA（4.5:1），深浅双主题都过
