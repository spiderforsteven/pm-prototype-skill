# 交付前质量检查表（L2 高保真原型）

> 出稿/交付前逐项核对。源自 UI UX Pro Max 的 canonical pre-delivery checklist + 本 skill 欧美基线，已按原型场景精简。**全部勾完才算交付。**

## 流程

- [ ] 只用与界面相关的检索/素材，不夹带无关数据
- [ ] 375px 小屏 + 横屏至少两种视口实测
- [ ] 深色模式**独立实测**对比度（不推断浅色值能延续）
- [ ] reduced-motion 下动画/过渡不破坏布局
- [ ] 交互用浏览器事件派发实测：点击 / 跳转 / Toast / 状态切换

## 视觉

- [ ] 无 emoji 当图标（用统一线性 SVG）
- [ ] 图标同一来源、同一描边风格（1.5-2px）
- [ ] 按钮 pressed 态不抖动布局（scale + 颜色即可）
- [ ] 颜色走语义 token，无散落硬编码色

## 交互

- [ ] 可点元素有 pressed 反馈（opacity/scale/涟漪，100ms 内可见）
- [ ] 触控目标 ≥44pt，间距 ≥8px
- [ ] 禁用态视觉清晰且不可交互
- [ ] 手势区域不互相冲突（tap / drag / 返回滑）
- [ ] 无 hover-only 交互（触屏要能完成）

## 深浅双主题

- [ ] 正文主/次级文字对比 ≥4.5:1（两主题分别验）
- [ ] 分隔线、描边、状态色在两种模式可区分
- [ ] 弹窗遮罩叠在真实背景上仍可读前景

## 布局

- [ ] 遵守安全区（刘海/底部横条/粘性栏不遮内容）
- [ ] 滚动内容不被 fixed/sticky 栏遮挡（原型里 tab bar 不压正文）
- [ ] 4/8dp 间距节奏贯穿组件-区块-页面
- [ ] 长文案在大屏不整行横贯（max-width 限制）

## 无障碍（欧美默认是硬性项，不是加分项）

- [ ] 装饰性图标 aria-hidden；有语义的图标有文本替代
- [ ] 图标按钮有可访问名，并播报选中/展开状态
- [ ] 表单字段有 label/hint/错误信息（禁 placeholder 当 label）
- [ ] 颜色不是唯一信息载体（配文字/图标）
- [ ] 自动轮播内容可暂停（无则删轮播）
- [ ] 焦点顺序 = 视觉顺序，键盘可达
